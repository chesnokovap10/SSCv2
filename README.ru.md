# SSCv2

[English](README.md) · **Русский**

SSCv2 передаёт звук Windows в Bluetooth-наушники через поддерживаемый адаптер MediaTek MT7921, MT7922 или MT7902. В меню трея доступны AAC, Samsung Scalable Codec (SSC, 24 бит / 48 кГц) и SSC UHQ (96 кГц). Пока кодек включён, сопряжённая Bluetooth-мышь может работать через SSCv2.

## Установка и обновление

Скачайте `ssc.exe` со страницы [релизов](https://github.com/chesnokovap10/SSCv2/releases) и запустите его. При первом запуске подтвердите запрос UAC. Программа установится в `C:\Program Files\SSCv2` и создаст ярлык на рабочем столе.

Для обновления запустите новый `ssc.exe`. В окне будут указаны установленная и новая сборки с хешами коммитов. Нажмите **Да**, чтобы закрыть работающий SSCv2, установить обновление и вернуться в выбранный режим кодека. При выборе **Нет** текущая версия продолжит работать. Windows может отдельно запросить права администратора.

**Настройки → Удалить программу…** возвращает адаптер Windows и удаляет установленную программу, службу, ярлык и сохранённые данные SSCv2. Для отладки без установки задайте `SSCV2_PORTABLE=1` перед запуском.

## Как включить звук в наушниках

1. Сопрягите наушники и мышь в Windows.
2. В меню SSCv2 выберите **Сопрячь устройство → Импорт сопряжённых в Windows**, затем выберите наушники и, при необходимости, мышь.
3. Выберите **AAC** или **SSC** в меню **Кодек**. Для битрейта начните с **Авто**.
4. Чтобы вернуть адаптер Windows, выберите **Выкл. (Bluetooth Windows)**. Пункт **Выход** также возвращает адаптер Windows перед завершением программы.

В режиме кодека SSCv2 использует адаптер MediaTek через WinUSB. При смене режима Bluetooth-устройства Windows на этом адаптере могут исчезать и появляться снова. В пункте **Инфо об устройствах…** видны адаптер, кодек, фактический битрейт, источник звука и состояние подключения.

### Громкость и приглушение

- В режиме кодека работают ползунок **Громкость наушников**, кнопка mute рядом с ним и клавиши громкости. Шкала **0–127**, шаг клавиш **4**. Ползунок виден при запуске потока и в режиме **Выкл.**
- В нативном режиме и в WinUSB SSCv2 передаёт команды громкости наушникам через AVRCP. Если наушники не подтверждают заданный уровень, SSCv2 может регулировать PCM до кодирования. Регулировка на самих наушниках работает отдельно от ползунка SSCv2.
- SSCv2 захватывает звук с выхода Windows по умолчанию через WASAPI loopback и удерживает этот выход в mute. Если Windows снимает mute, SSCv2 ставит его снова. При освобождении выхода SSCv2 восстанавливает исходное состояние приглушения.
- При смене режима SSCv2 переносит уровень и mute, когда стереовыход наушников доступен в Windows. После переподключения Windows может успеть активировать выход до применения сохранённого уровня.
- При обрыве связи с наушниками во время воспроизведения SSCv2 отправляет Play/Pause и освобождает физический выход на время ожидания. Медиакоманды с наушников передаются в Windows.

### Кодеки и битрейты

| Кодек | Возможные значения, кбит/с |
|---|---|
| AAC | 128, 160, 192, 224, 256 |
| SSC | 88, 96, 128, 192, 229, 256, 328 |
| SSC UHQ | 152, 250, 291, 308, 442, 584, 886 |

Меню фильтрует значения по размеру пакета и известному профилю наушников. **Авто** подбирает битрейт с учётом этих ограничений. Фактический битрейт отображается после запуска потока. При смене битрейта SSCv2 сначала пробует переоткрыть аудиопоток на том же Bluetooth-соединении. Возможна короткая пауза, а при ошибке движок может переподключить наушники.

- Для **Galaxy Buds2 Pro** проверенный предел SSC составляет **229 кбит/с**. Эта модель не объявляет поддержку SSC UHQ, поэтому в обычном меню режим может быть недоступен.
- **Настройки → Все битрейты** открывает экспериментальные значения выше проверенного предела. Значения, которые не помещаются в пакет, по-прежнему скрыты.
- **Настройки → Макс. MTU для Samsung Galaxy Buds2 Pro** разрешает пакеты до 1017 байт для таких режимов, как AAC 256 кбит/с. Другие наушники могут терять такие пакеты.

### Мышь и Bluetooth

SSCv2 поддерживает одну сопряжённую мышь BLE HID или классическую Bluetooth HID. Передаются движение, прокрутка и кнопки 1–5. Импортируйте сопряжение из Windows и выберите мышь в трее. Классическую мышь иногда нужно пошевелить, чтобы она подключилась.

Служба SSCv2 выполняет привилегированные операции с драйвером и ключами сопряжения. При работающей службе переключение режима и импорт ключей обходятся без запроса UAC. Трей и аудиодвижок работают отдельно от службы.

## Диагностика и сборка

**Настройки → Открыть папку журналов** открывает `%LOCALAPPDATA%\SSCv2\logs`. Для подробного журнала и команд управления меню включите **Отладка и API интерфейса**. Настройки и ключи сопряжения находятся в `%APPDATA%\SSCv2`, журнал службы — в `%ProgramData%\SSCv2`.

```bat
ssc.exe status
ssc.exe ctl status
ssc.exe ctl mode aac
ssc.exe ctl bitrate auto
ssc.exe ctl menu
```

Для сборки нужны Go 1.27 и MinGW-w64 (`gcc` и `g++` в `PATH`). Для переключения драйвера также нужны `makecat.exe` и `signtool.exe` из Windows SDK.

```bat
build.cmd
go test ./...
```

`build.cmd` собирает `bin\ssc.exe` через cgo с BTstack, FDK-AAC и [libssc](libssc/README.md). Версия и хеш коммита видны в меню и в информации об устройствах.

В `ssc.exe` встроены пакеты драйверов AVDTP и WaveRT для тестового режима Windows. Сборка и подпись этих пакетов описаны в [документации драйверов](driver/README.md).
