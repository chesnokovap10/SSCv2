# SSCv2

[English](README.md) · **Русский**

SSCv2 передаёт звук Windows в Bluetooth-наушники через поддерживаемый адаптер MediaTek MT7921, MT7922 или MT7902. В меню трея доступны AAC, Samsung Scalable Codec (SSC, 24 бит / 48 кГц) и SSC UHQ (96 кГц). Программа работает через WinUSB или через стек Bluetooth Windows в тестовом режиме Windows.

## Установка и обновление

Скачайте `ssc.exe` со страницы [релизов](https://github.com/chesnokovap10/SSCv2/releases) и запустите его. При первом запуске подтвердите запрос UAC. Программа установится в `C:\Program Files\SSCv2` и создаст ярлык на рабочем столе.

Для обновления запустите новый `ssc.exe`. В окне будут указаны установленная и новая сборки с хешами коммитов. Нажмите **Да**, чтобы закрыть работающий SSCv2, установить обновление и вернуться в выбранный режим кодека. При выборе **Нет** текущая версия продолжит работать. Windows может отдельно запросить права администратора.

Для обновления существующей установки без диалогов запустите новый `ssc.exe --update` из терминала с правами администратора.

**Настройки → Удалить программу…** возвращает адаптер Windows и удаляет установленную программу, службу, ярлык и сохранённые данные SSCv2. Для отладки без установки задайте `SSCV2_PORTABLE=1` перед запуском.

## Как включить звук в наушниках

1. Сопрягите наушники в Windows. Если планируете пользоваться мышью через WinUSB, сопрягите и её.
2. В меню SSCv2 выберите **Сопрячь устройство → Импорт сопряжённых в Windows**, затем выберите наушники и, при необходимости, мышь для WinUSB.
3. Выберите **AAC** или **SSC** в меню **Кодек**. Для битрейта начните с **Авто**.
4. Чтобы вернуть адаптер Windows, выберите **Выкл. (Bluetooth Windows)**. Пункт **Выход** также возвращает адаптер Windows перед завершением программы.

### Режимы Bluetooth

- **WinUSB** используется по умолчанию. SSCv2 устанавливает драйвер адаптера штатными средствами Windows и захватывает звук через WASAPI loopback. Устройства на этом адаптере могут исчезнуть из Windows, пока выбран кодек. В этом режиме работает поддержка Bluetooth-мыши через SSCv2.
- **Тестовый режим Windows** оставляет адаптер под управлением Bluetooth Windows. Подписанные пакеты драйверов AVDTP и WaveRT для этого режима входят в `ssc.exe`. Остальные Bluetooth-устройства, включая мышь, обслуживает Windows. Включите **Настройки → Тестовый режим Windows…** и перезагрузите компьютер. Тестовая подпись действует на весь компьютер. [Подробнее о драйверах](driver/README.md)

В пункте **Инфо об устройствах…** видны адаптер, кодек, фактический битрейт, источник звука и состояние подключения.

### Громкость и приглушение

- В режиме кодека работают ползунок **Громкость наушников**, кнопка mute рядом с ним и клавиши громкости. Шкала **0–127**, шаг клавиш **4**. Ползунок виден при запуске потока и в режиме **Выкл.**
- В нативном режиме и в WinUSB SSCv2 передаёт команды громкости наушникам через AVRCP. Если наушники не подтверждают заданный уровень, SSCv2 может регулировать PCM до кодирования. Регулировка на самих наушниках работает отдельно от ползунка SSCv2.
- В режиме WinUSB SSCv2 приглушает выход, с которого захватывает звук через WASAPI loopback, и восстанавливает исходное состояние приглушения при освобождении выхода.
- При смене режима SSCv2 переносит уровень и mute, когда стереовыход наушников доступен в Windows. После переподключения Windows может успеть активировать выход до применения сохранённого уровня.
- SSCv2 передаёт медиакоманды с наушников в Windows, в том числе Pause, если наушники отправили её через AVRCP. При обрыве связи во время воспроизведения SSCv2 может поставить плеер на паузу и дождаться переподключения наушников в выбранном режиме.

### Кодеки и битрейты

| Кодек | Возможные значения, кбит/с |
|---|---|
| AAC | 128, 160, 192, 224, 256 |
| SSC | 88, 96, 128, 192, 229, 256, 328 |
| SSC UHQ | 152, 250, 291, 308, 442, 584, 886 |

Меню фильтрует значения по размеру пакета и известному профилю наушников. **Авто** определяет битрейт при запуске потока. Для AAC в тестовом режиме используется **224 кбит/с**, а в WinUSB — до **256 кбит/с** с учётом размера пакета. Фактический битрейт отображается после запуска потока.

Если AAC, SSC или SSC UHQ не запускается с вручную выбранным битрейтом, SSCv2 сохраняет выбор режима и битрейта и показывает ошибку в трее. Чтобы повторить попытку, выберите другой битрейт. Пункт **Выкл** возвращает звук Bluetooth Windows.

- Для **Galaxy Buds2 Pro** проверенный предел SSC составляет **229 кбит/с**. Эта модель не объявляет поддержку SSC UHQ, поэтому в обычном меню режим может быть недоступен.
- **Настройки → Показывать все битрейты** открывает экспериментальные значения и позволяет попробовать SSC UHQ на наушниках, которые объявили только SSC. Запуск зависит от наушников и Bluetooth-стека.
- **Настройки → Макс. MTU для Samsung Galaxy Buds2 Pro** разрешает пакеты до 1017 байт в WinUSB. В тестовом режиме варианты с увеличенными пакетами открывает настройка **Показывать все битрейты**. Драйвер может отклонить такой поток при отправке первого пакета.

### Мышь и Bluetooth

В режиме WinUSB SSCv2 поддерживает одну сопряжённую мышь BLE HID или классическую Bluetooth HID. Передаются движение, прокрутка и кнопки 1–5. Импортируйте сопряжение из Windows и выберите мышь в трее. Классическую мышь иногда нужно пошевелить, чтобы она подключилась.

Служба SSCv2 выполняет привилегированные операции с драйвером и ключами сопряжения. Она нужна для тестового режима Windows. При работающей службе переключение режима и импорт ключей обходятся без запроса UAC. Трей и аудиодвижок работают отдельно от службы.

## Диагностика и сборка

**Настройки → Открыть папку журналов** открывает `%LOCALAPPDATA%\SSCv2\logs`. Для подробного журнала и команд управления меню включите **Отладка и API интерфейса**. Настройки и ключи сопряжения находятся в `%APPDATA%\SSCv2`, журнал службы — в `%ProgramData%\SSCv2`.

```bat
ssc.exe status
ssc.exe ctl status
ssc.exe ctl mode aac
ssc.exe ctl bitrate auto
ssc.exe ctl menu
```

Для сборки нужны Go 1.27 и MinGW-w64 (`gcc` и `g++` в `PATH`).

```bat
build.cmd
go test ./...
```

`build.cmd` собирает `bin\ssc.exe` через cgo с BTstack, FDK-AAC и [libssc](libssc/README.md). Версия и хеш коммита видны в меню и в информации об устройствах.

После изменения списка исходников C или C++ запустите `go run ./tools/genwrap`. При сборке обёртки cgo проверяет команда `go run ./tools/genwrap -check`. Приложение использует энкодер SSC из `libssc/src`. Декодер, испытательный стенд и инструменты реверс-инжиниринга используются для тестов и исследований libssc.

В `ssc.exe` встроены пакеты драйверов AVDTP и WaveRT для тестового режима Windows. Сборка и подпись этих пакетов описаны в [документации драйверов](driver/README.md).
